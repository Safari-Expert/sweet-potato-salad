# Customer-authorized hotel catalog cleanup

Use this procedure only when the customer explicitly requests clearing hotels from a specified account and selection. Onboarding, preparing files or replacing rates preserves existing hotel IDs. Confirm the effective account through the connected MCP tools. List all applicable hotel pages and record the selected hotel IDs, owners and proposed actions. Match identities by ID and ownership. Ordinary catalog cleanup does not require an export or snapshot unless requested.

| Ownership | Treatment |
| --- | --- |
| Owned by the selected customer | Apply an explicitly authorized removal through a supported customer tool. Check the affected rooms and rates before proceeding. |
| Shared with the selected customer | Remove only this customer's access if the connected tools support that action and the customer authorized it. Preserve the original hotel. |
| Different or unknown ownership | Hold the item and report the unresolved ownership. |

Use only the operations and permissions the customer's connection actually exposes. When a required removal or unshare operation is unavailable, report the specific pending action. Restrict work to the selected hotels. Preserve unrelated hotels, rooms, accounts and product families. On an uncertain outcome, list the catalog again before retrying. Record removed, unshared, failed and remaining counts separately. Verify each selected ID against a fresh list before resuming a separately authorized replacement import. An absent shared item establishes only that the customer no longer sees it.
