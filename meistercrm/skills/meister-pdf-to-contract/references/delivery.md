# Supplier evidence and lodge folders

Identify each source by filename, issue/amendment date and page. Distinguish physical PDF pages (one-based, used for extraction) from printed page labels. Read the whole applicable section including regional taxes, restrictions, age, meals and validity clauses. Follow page continuations. Preserve names, currency and unit exactly in the evidence sheet. An unsupported amount stays blank and the reason is recorded. Evidence of a free charge gives a numeric zero.

Use one folder per identifiable lodge under the specified customer destination. Search the folder for a matching season/edition and file IDs. Inspect existing material before updating. Handle unrelated existing files with the customer if the three-file limit requires moving or deleting them. Keep at most:

- One supplier PDF. For a single lodge retain the original unchanged. For several lodges include only this lodge's rate pages and the common pages that apply to it, in original order. Check the first/last row, continued table headings, inclusions, levy, age and holiday clauses. Record original physical page numbers and their new positions; retain printed page labels. If one page mixes confidential rates from different lodges, produce a visually checked, actually redacted extract using an authorized PDF tool, or hold that extract. A drawn rectangle does not redact the underlying text. Reopen the saved PDF. The exact saved bytes are also the CRM attachment.
  When two editions or a separate amendment supply the rates, keep each original in the customer’s authorized source location. Assemble one lodge PDF from the relevant original pages of each source, including relevant rate pages, shared terms and amendments. Keep page order within each document. On `Original`, record the source filename, edition, original physical page and delivered page for each rate or amendment. For example, an amendment on page 2 of a second PDF can be page 7 of the lodge PDF. Check both references after reopening and attach this exact lodge PDF.
- One final XLSX. The first worksheet, **Contracts**, holds payable CRM rows with unmodified template headers. Use typed numbers and dates, distinguish an available zero from a missing value, and reopen the file to verify it. The second worksheet, **Original**, retains original supplier amounts and units, the page map, the source TDL statement, decision, basis, raw derived amounts and final results for each row. Keep the same workbook file and Drive ID when correcting the same deliverable. Verify no prior rows disappear when revising a subset. Keep validation responses, scripts and source staging data outside the lodge folder.
- One optional short notes file for human context that cannot fit in the workbook, such as a long list of affected seasons. The master in MeisterCRM remains the place for unresolved review questions and human decisions.

Use a connected Drive capability that uploads or updates binary PDF/XLSX without conversion and can retrieve/verify the result. If the available connector only supports native spreadsheets, retain the completed bytes until delivery can be finished. For a local destination read back both finalized files and report their paths. Avoid a separate import workbook, duplicate original, or tracking spreadsheet.
